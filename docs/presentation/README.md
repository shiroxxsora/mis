# Презентация MIS

Файл: **[MIS-presentation.pptx](MIS-presentation.pptx)**

## Содержание (13 слайдов)

1. Титул  
2. О системе  
3. Технологический стек  
4. Как пользователь работает в системе  
5. Архитектура (1 слайд)  
6. Жизненный цикл приёма (автомат состояний)  
7. Версионирование БД через Liquibase  
8. Тестирование и качество  
9. Роли и сценарии  
10. Искусственный интеллект  
11. Безопасность  
12. Запуск и демо  
13. Завершение  

Цвета совпадают с `frontend/src/index.css` (`#ff4b23`, `#2a2a2e`, `#ffe1d7` и др.).

## Пересборка

```bash
python scripts/generate_presentation.py
```

Требуется Node.js (`npx`) для рендера Mermaid → PNG. Исходники диаграмм: [`diagrams/`](diagrams/). Картинки вставляются **без растягивания** (пропорции сохраняются); слайд про приём поясняет термин FSM по-русски.
